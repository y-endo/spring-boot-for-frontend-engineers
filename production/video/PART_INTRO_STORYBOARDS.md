## 1. 11本共通の型

5つの場面を、必ずこの順に置く。

| 場面 | 内容 | 長さの目安 |
| --- | --- | --- |
| A タイトル | 「第N部」と部の題名のタイトルカード（`K.title_card`、`until_line=0`） | 4〜6秒 |
| B 困りごと | 前の部の終わりの時点で、QuickVote に残っている問題（第0・1・2・8部は、読者の困りごと）。1〜3行 | 8〜12秒 |
| C 章の道のり | 章ごとのカードが一列に並び、話に合わせて1枚ずつ光る。各章に短いラベルと、中身を表す簡単な動き | 35〜45秒 |
| D 前→後 | 部の終わりの姿。左に「前」、右に「後」の2枚のパネル | 8〜12秒 |
| E 最後の1行 | 一言まとめを大きく表示 | 4〜6秒 |

「型」で揃えるのは場面の順序、章カードの形、色の意味、前→後の2枚構成まで。**B と C の動きは、部ごとに中身に合わせて変える**（各本の「困りごとの動き」「章ごとのミニ動き」を参照）。

- 章の頭の短い行（「第10章は、Spring Bootの全体像。」）で、カードを光らせて、ミニ動きの土台を出す。続く行で動きを見せる。

## 2. 色と配置のルール（`STORYBOARDS.md` の共通ルールに従う）

- コードは映さない。画面の文字は短いラベルだけ。場面ごとに要素を入れ替え（`pop_out`）、カメラの寄り引きを2〜4回、強調は `pulse` / `shake` / `recolor`。
- 失敗は **RED**、成功は **GREEN**、待ち・注意・「まだ残っている」は **YELLOW**。色だけでなく、形・ラベルでも区別する（✕、OK、待ち、「まだ」など）。
- シリーズ共通の色の割り当て（この11本だけの約束）：

| 色 | 使う対象 |
| --- | --- |
| TEAL | 章カードの「いま話している章」。部のバッジ。これ以外には使わない |
| BLUE | サーバー・アプリ・データの流れ（矢印） |
| ORANGE | 利用者・ブラウザ・リクエスト（封筒） |
| PURPLE | DB・保存されたデータ |
| DARK / GRAY | 未到達の章カード、使わなくなった要素、背景の枠 |

- **図は y > -2.8 に配置**する（字幕と重ならない）。さらに次の領域分けを共通にする。

| 領域 | 座標の目安 | 使い方 |
| --- | --- | --- |
| 部のバッジ | 左上 (-6.7, 3.65) | B から D まで、「第N部」を TEAL のチップで出しっぱなし |
| 動きの領域 | y が -1.2〜3.2、x が -7〜7 | B のイラスト、C のミニ動き、D の前→後 |
| 章カードの列 | y = -2.15（高さ1.1。下端 -2.7） | C の開始で、左から順に `pop_in`。D の終わりで退場 |

- **章カードの形**：角丸の矩形。上段に「第N章」（小さく）、下段にラベル。幅は `min(3.6, (14.6 - 0.2×(n-1)) / n)`（n は章数）。ラベルは10字前後。**章が6枚以上の部では、ラベルを5字前後で2行に折り返す**（本書では折り返し位置を `/` で示す）。
- **章カードの3状態**：未到達（DARK の地、GRAY の文字）→ いま（TEAL の地、WHITE の文字、`pulse` 1.12、カードの上にミニ動きの領域が切り替わる）→ 済み（BG2 の地、TEAL の文字、右上に小さな ✓）。次の章が光るとき、前の章を「済み」にする。
- **ミニ動き**：章の頭の行で土台を `pop_in`、続く行で動かし、次の章の頭の行の2フレーム前に `pop_out`。登場する語は、図形・アイコン・矢印と、短いラベルだけ。
- **D の前→後**：左右に角丸のパネル（左「前」は DARK、右「後」は BG2 に TEAL の枠）。間に矢印。「後」に GREEN の ✓ を付けた項目、「前」に RED の ✕ を付けた項目を並べる。**まだ守れていないものがある部は、「後」の下に YELLOW のチップで「まだ」を出す**（正直に見せる）。この間、章カードは全点灯（TEAL）で一度脈打ち、そのあと退場。
- **E の最後の1行**：他の要素をすべて `pop_out`。中央に一言まとめを大きく（1行13字以内なら 1 行、超えるなら 2 行。サイズ 0.9〜1.0）。下に小さく「第N部」。最後の行が終わっても、末尾の余韻（1.2秒）のあいだ出したままにする。
