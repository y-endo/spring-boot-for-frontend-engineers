# 第0部 はじめに

この部では、教材の歩き方を確認し、手元に開発環境をそろえます。環境さえ動けば、あとは先へ進めます。

## この部でできるようになること

- この教材が「何を目指し、何を扱わないか」を説明できる
- AIと一緒に学ぶときの3つの原則を、自分のルールとして持てる
- 通しの題材 QuickVote（即席投票ボード）の完成形を頭に描ける
- JDK 25・IntelliJ IDEA・Docker・Maven Wrapper が動く環境を作り、「Hello」と「DBにつながった」を確認できる

## 進め方の目安

| 項目 | 目安 |
| --- | --- |
| 第0章 | 読むだけ。30分 |
| 第1章 | 手を動かす。1〜2時間（ダウンロード待ちを含む） |
| 合格の目安 | 第1章末の「環境チェックリスト」がすべて埋まること |

!!! tip "急がなくてよい理由"
    環境構築は教材の中でいちばん退屈ですが、詰まると先へ進めなくなる場所でもあります。
    時間を惜しまず、確認コマンドを1つずつ通してください。
