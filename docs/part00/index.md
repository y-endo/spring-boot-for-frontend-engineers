??? note "字幕全文"
    第0部は「はじめに」です。歩き方を決めて環境を整えます。
    Javaを学ぶと決めても、何から始めればいいのか分かりません。
    どこまでやれば終わりなのかも、まだ見えません。
    しかも手元には、動かせる環境もありません。
    第0章はこの教材の歩き方です。
    目指すのはサーバーが守る約束を、決めて、作って、壊して確かめること。
    扱わない範囲もここで決めます。学習時間の目安は約200時間です。
    AIと学ぶ原則は3つです。まず予測してから聞く。
    次に出力は動かして観察する。説明できないコードは使わない。
    通しの題材は、QuickVoteという匿名の投票サービスです。
    会議や飲み会でその場で決めるために使います。
    第1章は開発環境を整えます。
    JDK 25、IntelliJ IDEA、Dockerを入れます。
    Maven Wrapperも使えるようにします。
    確認するのは2つです。Helloが出ることと、DBにつながること。
    環境づくりは詰まると、全部止まるので、確認を1つずつ通します。
    この部が終わると、教材の進め方が決まります。
    手元ではJavaが動き、DBにもつながっています。
    最初に、進め方と環境をそろえる。
<!-- part-intro:end -->

この部では、教材の歩き方を確認し、手元に開発環境をそろえます。環境さえ動けば、あとは先へ進めます。

## この部でできるようになること

- この教材が「何を目指し、何を扱わないか」を説明できる
- AIと一緒に学ぶときの3つの原則を、自分のルールとして持てる
- 通しの題材 QuickVote（即席投票ボード）の完成形を頭に描ける
- JDK 25・IntelliJ IDEA・Docker・Maven Wrapper が動く環境を作り、「Hello」と「DBにつながった」を確認できる
